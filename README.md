# Turing Machine Simulator

A simple web-based **Turing Machine Simulator** that allows users to create, configure, and simulate Turing Machines directly in a web browser.

## 🌐 Live Demo

**[Open Turing Machine Simulator](https://techabhi2005.github.io/turing-machine-simulator/)**

## 📌 About the Project

This project is designed to help students understand the working of a **Turing Machine** through an interactive simulation.

Users can define the states, input symbols, transitions, and input string, and then run the machine to observe whether the input is **Accepted or Rejected**.

## ✨ Features

* Create and configure Turing Machine states
* Define transition rules
* Enter input strings
* Simulate the Turing Machine step by step
* Display the current machine state
* Show tape contents
* Identify Accepted or Rejected results
* Simple and user-friendly interface
* Runs directly in a web browser

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* GitHub Pages

## ⚙️ How to Use

1. Open the **Live Demo**.
2. Enter the required Turing Machine states and symbols.
3. Define the transition rules.
4. Enter the input string.
5. Start the simulation.
6. Observe the tape and machine state.
7. Check whether the input is accepted or rejected.
